# miniguia-estudos-notebooklm
Esse repositório tem o objetivo de ser uma atividade pratica de estudo do uso do notebooklm

Projeto: Melhores Táticas para Xadrez de Brancas
Objetivo do Conteúdo
Este conteúdo tem o objetivo de encontrar as melhores táticas de xadrez jogando de brancas, baseado em conteúdos de livros e jogos históricos, com as jogadas e táticas mais utilizadas e com maior chance de sucesso.

Passo 1: Pesquisa de fontes no NotebookLM

Levantar os principais livros para jogar de brancas;

Analisar o histórico de jogadas no Chess.com.

Passo 2: Criação de prompts para obter informações e táticas
(Utilize os comandos abaixo no chat)

"Atue como um professor de xadrez focado em jogar de brancas. Liste as principais aberturas (com maior taxa de vitória), táticas e jogadas mais comuns. Separe-as por nível de rating, indique as bases do xadrez e exercícios para treinamento. Traga as informações em uma linguagem simples para iniciantes."

"Explique o Sistema London."

"Mande o plano de jogo."

"Monte um guia do Sistema London com imagens."

Passo 3: Geração de relatório
(Comando para compilar o conteúdo escrito)

"Crie um conteúdo informativo em linguagem simples para um iniciante em xadrez. O texto deve ser focado em jogar de brancas, contendo as bases do xadrez, as principais jogadas, aberturas, principais respostas, situações de jogo e exercícios práticos de táticas."

Passo 4: Geração de infográfico
(Informações que devem constar na arte visual)

Principais aberturas;

Quantidade de vezes em que foram jogadas;

As taxas de sucesso e fracasso de cada uma delas
